# Stream Deck Emulator

<p align="center">
  <img alt="Stream Deck Emulator: громкость и яркость на Stream Deck +, затем управление плеером на Stream Deck Neo" src="assets/demo.gif" width="800">
</p>

Виртуальный Stream Deck для настоящего приложения Stream Deck. Эмулятор представляется Windows как USB-устройство, поэтому приложение Stream Deck, ваши плагины и профили работают так же, как с железом.

Проект сделан для разработчиков плагинов, у которых нет всех моделей.

> [!WARNING]
> Это неофициальный проект. Он не связан с Elgato и Corsair, не одобрен и не поддерживается ими. Stream Deck — товарный знак Corsair Memory, Inc.

## Поддерживаемые модели

| Модель | Идентификатор | Что эмулируется |
|---|---|---|
| Stream Deck + | `plus` | 8 клавиш, 4 диска, сенсорная полоса |
| Stream Deck Neo | `neo` | 8 клавиш, 2 сенсорные клавиши, инфо-экран |
| Stream Deck MK.2 | `mk2` | 15 клавиш |

## Возможности

- **Интерфейс в браузере**: Нажимайте клавиши, крутите и нажимайте диски, кликайте, удерживайте и перетаскивайте по сенсорной полосе и смотрите, что приложение рисует на каждом экране.
- **Несколько устройств сразу**: Каждая модель подключается и отключается отдельно. Остальные продолжают работать.
- **Запуск без браузера**: Модели можно подключить из командной строки.
- **Один исполняемый файл**: Без зависимостей, кроме клиента USB/IP.

## Требования

- **Операционная система**: Windows 10 или 11
- **Клиент USB/IP**: [usbip-win2](https://github.com/vadimgrn/usbip-win2), который создаёт виртуальное USB-устройство (проверено с 0.9.7.8)
- **Приложение Elgato Stream Deck**
- **Go**: версия 1.27 или новее для сборки

## Быстрый старт

1. Установите usbip-win2.
2. Соберите и запустите эмулятор:

   ```
   go build -trimpath -o bin/emulator.exe ./cmd/emulator
   bin\emulator.exe
   ```

3. Откройте <http://127.0.0.1:8484>.
4. Выберите модель в списке над клавишами и нажмите **Подключить**. Через несколько секунд она появится в приложении Stream Deck.
5. Нажмите **Отключить**, чтобы отсоединить устройство. Приложение Stream Deck запомнит устройство и его профили, как и с настоящим железом.

## Флаги

| Флаг | По умолчанию | Назначение |
|---|---|---|
| `-usbip` | `127.0.0.1:3240` | Адрес сервера USB/IP |
| `-ui` | `127.0.0.1:8484` | Адрес веб-интерфейса |
| `-usbip-cli` | поиск | Путь к клиенту `usbip`. По умолчанию эмулятор ищет его в `PATH`, затем в `C:\Program Files\USBip`. |
| `-connect` | нет | Модели, которые подключаются при запуске, например `-connect plus,neo`. |

## HTTP API

Веб-интерфейс общается с эмулятором по HTTP, и скрипты могут делать то же самое: нажимать клавиши, крутить диски и забирать то, что нарисовало приложение. API пока не стабилен.

<details>
<summary>Запросы и примеры</summary>

`{id}` — идентификатор модели: `plus`, `neo` или `mk2`. Примеры написаны для POSIX-оболочки и адреса по умолчанию.

| Запрос | Результат |
|---|---|
| `GET /api/devices` | Модели, их раскладка и состояние подключения |
| `POST /api/devices/{id}/connect` | Подключить устройство |
| `POST /api/devices/{id}/disconnect` | Отключить устройство |
| `POST /api/devices/{id}/input` | Нажать клавишу или диск, повернуть диск, коснуться полосы |
| `GET /api/devices/{id}/key/{index}` | Изображение клавиши, JPEG |
| `GET /api/devices/{id}/strip` | Изображение сенсорной полосы, PNG |
| `GET /api/devices/{id}/screen` | Изображение инфо-экрана, JPEG |
| `GET /api/events` | Server-sent events об изменениях экранов и подключения |

Успешный `POST` отвечает `204`. Ошибка приходит с JSON-телом, например `{"code":"unsupported_input"}`. Клавиша или экран, на которых приложение ещё ничего не нарисовало, отвечают `204` без тела.

Клавиши нумеруются с 0, слева направо и сверху вниз. Сенсорные клавиши Neo идут после обычных: 8 и 9. Диски нумеруются с 0, слева направо.

Нажать и отпустить клавишу 0:

```bash
curl -X POST http://127.0.0.1:8484/api/devices/plus/input -d '{"type":"key","index":0,"down":true}'
curl -X POST http://127.0.0.1:8484/api/devices/plus/input -d '{"type":"key","index":0,"down":false}'
```

Повернуть диск 1 на три щелчка, затем нажать его. Отрицательный `ticks` крутит в другую сторону.

```bash
curl -X POST http://127.0.0.1:8484/api/devices/plus/input -d '{"type":"dialRotate","index":1,"ticks":3}'
curl -X POST http://127.0.0.1:8484/api/devices/plus/input -d '{"type":"dialPress","index":1,"down":true}'
curl -X POST http://127.0.0.1:8484/api/devices/plus/input -d '{"type":"dialPress","index":1,"down":false}'
```

Коснуться полосы. `kind` равен `1` для касания, `2` для долгого нажатия и `3` для перетаскивания из `x`, `y` в `x2`, `y2`. Координаты заданы в пикселях полосы, 800 на 100 у Stream Deck +.

```bash
curl -X POST http://127.0.0.1:8484/api/devices/plus/input -d '{"type":"touch","kind":1,"x":100,"y":50}'
curl -X POST http://127.0.0.1:8484/api/devices/plus/input -d '{"type":"touch","kind":3,"x":100,"y":50,"x2":400,"y2":50}'
```

Сохранить то, что приложение нарисовало на клавише 0:

```bash
curl -o key0.jpg http://127.0.0.1:8484/api/devices/plus/key/0
```

Изображения отдаются в том виде, в каком их прислало приложение. Neo и MK.2 получают их повёрнутыми на 180 градусов; какие модели так делают, показывает поле `rotated` в `GET /api/devices`.

</details>

## Ограничения

- Neo реализован по открытым описаниям протокола и не сверялся с настоящим устройством. Сообщайте обо всём, что приложение показывает иначе.
- По одному экземпляру каждой модели.
- Автоматическое подключение работает с usbip-win2 в Windows. В других системах сервер USB/IP запускается, но подключать нужно вручную.
- У веб-интерфейса нет аутентификации. Оставляйте его на локальном адресе: любой, кто может открыть страницу, может нажимать ваши клавиши.
